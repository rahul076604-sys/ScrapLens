Dispose Waste the Right Way

Different types of waste require different disposal methods. Use this guide to understand how each waste category should be handled, reused, recycled, or disposed of.

🔋

Battery

Special Disposal

♻️ Recommended Action

  • ✓ Take batteries to a designated collection point.
  • ✓ Keep used batteries separate from regular waste.
  • ✓ Handle damaged batteries carefully.
⚠️ Do not put batteries in normal household waste.
🌱

Biological

Organic Waste

♻️ Recommended Action

  • ✓ Keep organic waste separate from recyclables.
  • ✓ Place suitable food waste in a compost bin.
  • ✓ Use composting where available.
🌿 Organic waste can often be converted into compost.
🥛

Glass

Recyclable

♻️ Recommended Action

  • ✓ Rinse glass containers before recycling.
  • ✓ Put recyclable glass in the appropriate collection bin.
  • ✓ Handle broken glass carefully.
⚠️ Wrap broken glass safely before disposal.
📦

Cardboard

Recyclable

♻️ Recommended Action

  • ✓ Flatten cardboard boxes.
  • ✓ Keep cardboard clean and dry.
  • ✓ Send it to the appropriate recycling stream.
📦 Reuse cardboard boxes whenever possible.
👕

Clothes

Reusable

♻️ Recommended Action

  • ✓ Donate clothes that are still usable.
  • ✓ Reuse old clothes where possible.
  • ✓ Use textile collection programs when available.
👕 Consider donation or reuse before disposal.
🔩

Metal

Recyclable

♻️ Recommended Action

  • ✓ Separate metal from general waste.
  • ✓ Take scrap metal to a recycling facility.
  • ✓ Clean suitable containers before recycling.
🔩 Metal can often be recovered and recycled.
✨

Non-Waste

Not Waste

♻️ Recommended Action

  • ✓ Keep usable objects instead of discarding them.
  • ✓ Reuse or donate useful items.
  • ✓ Avoid unnecessary disposal.
💡 If an item is still useful, consider keeping or donating it.
📄

Paper

Recyclable

♻️ Recommended Action

  • ✓ Keep paper clean and dry.
  • ✓ Separate paper from food and liquid waste.
  • ✓ Place recyclable paper in the appropriate collection.
📄 Reuse paper before recycling whenever possible.
🧴

Plastic

Recyclable

♻️ Recommended Action

  • ✓ Empty and rinse recyclable containers.
  • ✓ Follow local plastic collection rules.
  • ✓ Reuse suitable containers where possible.
⚠️ Avoid burning plastic because it can release harmful pollutants.
👟

Shoes

Reusable

♻️ Recommended Action

  • ✓ Donate wearable shoes.
  • ✓ Repair usable shoes where possible.
  • ✓ Use footwear collection programs when available.
👟 Usable shoes can often be reused or donated.
🗑️

Trash

General Waste

♻️ Recommended Action

  • ✓ Use general waste only for non-recyclable items.
  • ✓ Separate recyclable materials first.
  • ✓ Keep waste contained to prevent littering.
🗑️ Check whether an item can be reused, recycled, or composted first.

🌱 ScrapLens Tip

Before throwing something away, ask yourself: Can I reuse it, recycle it, or compost it? Small sorting decisions can help reduce unnecessary waste.
